# Library Management System - QUICK START GUIDE 🚀

## The Simplest Way to Get Started

---

## 📋 Prerequisites (One Time Only)

### Do You Have Node.js?
Open Command Prompt and type:
```
node -v
```

**If you see a version number:** ✅ You're ready!
**If "command not found":** Go to https://nodejs.org/ and install it

**Important:** When installing Node.js, check "Add to PATH"

---

## ▶️ RUN THE APPLICATION (3 Seconds)

### **Windows:**
```
Double-click: run-desktop.bat
```

### **PowerShell:**
```powershell
.\run-desktop.ps1
```

### **Command Prompt:**
```bash
npm install
npm start
```

---

## 📱 What Happens Next

```
1. Terminal window appears
   └─ This is normal, leave it open

2. Electron window launches
   └─ Your desktop app opens

3. Login page appears
   └─ Ready to use!
```

## 📚 Use the Application

### **Browse Books**
- Click "Browse Books" in navigation
- See all available books
- Search by title, author, or ISBN
- Filter by category

### **Borrow a Book**
- Find a book you like
- Click "Borrow"
- Confirm when asked
- Book appears in "My Books"

### **Return a Book**
- Go to "My Books"
- Find the borrowed book
- Click "Return Book"
- Fines calculated automatically if overdue

### **View Profile**
- Click "Profile"
- See your information
- Update personal details
- View payment method

---

## 📂 Where is My Data?

**All data saved in:** `/data/` folder
- `users.json` - Your account
- `books.json` - Book catalog
- `borrowing.json` - Your borrowing history
- `payment_methods.json` - Your card
- `activity_log.json` - Your activities

**All on your computer - 100% private!**

## ❌ If Something Goes Wrong

### "Node.js not found"
→ Install Node.js from https://nodejs.org/

### "PHP not found"
→ PHP is already on your system
→ Ensure it's in your PATH

### Application won't start
→ Run in Command Prompt to see error:
```bash
npm start
```

### Data not saving
→ Check that `/data/` folder exists
→ Check folder permissions

### Port 8000 in use
→ Close other applications
